# EcomSniper Alt (MVP)

Non-API Chrome extension for creating Amazon and eBay draft listings.

## Usage

1. Open `chrome://extensions` in Chrome.
2. Enable **Developer mode**.
3. Click **Load unpacked** and select this project folder (the folder containing `manifest.json`).

## Development

All source files are plain JavaScript under `src/`, so no build step is required. If you add a bundler later, output to a `dist/` directory, which is ignored by Git.
